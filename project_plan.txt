- npm run dev: start local development server.
- npm run build: create a production build.
- npm run lint: run Oxlint.
- npm run server: start the API after creating .env from .env.example.
- npm run server:watch: start the API with Node watch mode.
- npm run token -- driverId=123 role=driver: print a 24-hour JWT.
- npm run dev: start the frontend from frontend/.

API contract
------------
- POST /invoice accepts passengerName, driverName, vehicleNumber, pickup, drop, distance, fare, gst, and discount.
- POST /invoice responds with 201 and the saved invoice including totals and expiresAt.
- GET /invoice/:id returns the saved invoice or 404 when it does not exist.
- GET /invoice returns all invoices, sorted newest first, with optional from and to date filters.
- DELETE /invoice/:id manually removes an invoice; MongoDB TTL remains the automatic cleanup path.
- GET /reports returns aggregate invoice totals; add from and to query parameters for a date range.
- GET /reports also returns daily, weekly, and monthly earnings series for Chart.js.
- POST /share/:id creates or reuses a short invoice share token.
- GET /share/:token retrieves an invoice from its short share token.
- GET /profile fetches the authenticated driver's saved details.
- POST /profile/save saves or updates the authenticated driver's details.
- DELETE /profile/clear removes the authenticated driver's saved details.
- MongoDB Atlas credentials are never committed; MONGODB_URI is loaded from .env.
